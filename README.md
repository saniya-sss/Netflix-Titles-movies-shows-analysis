Netflix Movies & TV Shows Analysis | Power BI
**Project Overview**

This project analyzes the Netflix Movies and TV Shows dataset using Power BI to uncover insights into Netflix’s content library. 
The dashboard helps understand content distribution, genre popularity, and trends across release years using interactive visuals and DAX measures.

 **Objectives**

Analyze the total number of movies and TV shows
Understand genre-wise distribution of content
Compare movies vs TV shows
Explore trends based on release year and ratings
Enable dynamic analysis using slicers

**Tools & Technologies**

Power BI
DAX (Data Analysis Expressions)
Data Cleaning & Modeling
Interactive Visualizations
